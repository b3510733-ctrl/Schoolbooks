ШАГ 1. КАК ОТКРЫТЬ САЙТ
-----------------------
Просто откройте файл index.html двойным кликом в браузере (Chrome, Edge, Firefox).
Сайт работает локально, интернет не нужен.

ШАГ 2. КАК ДОБАВИТЬ СВОЮ КНИГУ
------------------------------
1. Положите PDF-файл книги в папку books/
2. Откройте файл script.js в любом текстовом редакторе (Блокнот подойдёт)
3. Скопируйте любой блок в списке BOOKS (от { до }, включая запятую в конце)
4. Вставьте после него и измените значения:
   - id    — поставьте следующий номер (например, 17)
   - title — название учебника
   - author— авторы
   - class — класс: 5, 6, 7 ... 11
   - subject — предмет ТОЧНО как в фильтрах: "Математика", "Русский язык",
     "Литература", "История", "Физика", "Биология", "Английский язык", "Химия"
     (новый предмет = добавить новую кнопку в index.html)
   - file  — путь к файлу, например "books/moya-kniga.pdf"
   - emoji — иконка обложки, color — цвет обложки (любой hex-код, напр. "#3b82f6")
   - desc  — краткое описание

ШАГ 3. КАК РАЗМЕСТИТЬ В ИНТЕРНЕТЕ (бесплатно)
--------------------------------------------
Самый простой способ — GitHub Pages:
1. Создайте аккаунт на github.com
2. Создайте репозиторий с именем, например, schoolbooks
3. Загрузите туда все файлы и папки (books/, covers/ можно не загружать, если пустые)
4. Зайдите в Settings -> Pages -> выберите ветку main -> Save
5. Через пару минут сайт будет доступен по адресу:
   https://ВАШ_НИК.github.io/schoolbooks/

Альтернативы: Netlify Drop (netlify.com/drop — просто перетащить папку),
Vercel, или любой хостинг с поддержкой статики.

СТРУКТУРА ПРОЕКТА
------------------
schoolbooks/
├── index.html   — главная страница (разметка)
├── styles.css   — внешний вид (цвета, шрифты, карточки)
├── script.js    — каталог книг + логика поиска и фильтров
├── books/       — сюда кладите PDF-файлы книг
└── covers/      — (опционально) обложки в виде картинок
